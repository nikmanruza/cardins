# Roadmap

## Phase 1 — Foundation (in progress)
- [ ] Design tokens + fonts (dark premium gaming system)
- [ ] Site shell: announcement bar, sticky header, mobile drawer, footer
- [ ] Home, Shop (search/filter/sort), category pages, product detail
- [ ] Catalog data in Lovable Cloud (categories + products, seeded)

## Phase 2 — Cart & checkout
- [ ] Cart drawer + persisted cart, cart page
- [ ] Checkout flow with order creation
- [ ] Payment provider integration, server-verified payment status -> order `paid`
- [ ] End-to-end verification: browse -> cart -> checkout confirmation

## Phase 3 — Digital delivery
- [ ] Inventory items (keys/assets) with atomic allocation
- [ ] Automatic delivery after confirmed payment, per product type rules
- [ ] Customer library + order history + delivery emails

## Phase 4 — Admin
- [ ] Auth + user roles table with role-based access
- [ ] Product management, fulfillment inventory management
- [ ] Orders queue driven by real payment statuses, audit log
